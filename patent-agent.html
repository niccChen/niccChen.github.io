Patent Agent

Patent prior-art search

A tool-using LLM agent that turns patent claims and invention ideas into ranked prior art, limitation-level evidence charts, and source-grounded answers.

Patent Agent combines query planning, PatentSBERTa embeddings, a shared FAISS index, and learned reranking to retrieve relevant patents. Claim decomposition maps individual limitations to supporting passages in titles, abstracts, and claims.

A LangGraph workflow separates planning, retrieval, reranking, evidence alignment, answer synthesis, and verification. Follow-up queries can reuse the existing working set, and the system provides FastAPI and Streamlit interfaces.

The project evaluates prior-art ranking on the PANORAMA PAR4PC validation split and includes a small, internally annotated study of grounded answer quality.
