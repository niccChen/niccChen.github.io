ECG Trace Reconstruction

Digitize EKG · Python project

This project explores how fragmented ECG image traces can be reconnected using classical computer vision. Starting from a prepared trace crop, the workflow thresholds the image, skeletonizes its foreground, identifies connected components, and detects endpoints.

The current method estimates local endpoint directions, matches compatible fragments, and draws cubic connections that transition between endpoint widths. Crossing checks and pixel-grid alignment help control how new geometry is added while preserving the existing binary foreground.

The project includes component-distance and endpoint-based baselines, a runnable Jupyter walkthrough, debug overlays, and synthetic geometry regression checks. The current outputs are repaired image masks and centerlines; time–voltage calibration and one-dimensional waveform export remain future work.

Tools & methods

Python · OpenCV · NumPy · scikit-image · SciPy · Matplotlib · Jupyter
